Your Reminders, on the morning receipt.

This private page helps you build a read-only export in Apple Shortcuts. It does not request your Apple password.

Setup guide is ready. On the iPhone, connect Tailscale and enable Use Tailscale DNS so the private server name resolves.

Upload URL



Authorization header
Scan the new pairing QR code in the desktop app to get your upload token.
The token can replace this app’s Reminders snapshot. Keep it private. Creating another token on the desktop revokes this one.

2. Build “Send Reminders to Receipt”


Open Shortcuts on your iPhone, tap +, and name the shortcut Send Reminders to Receipt. Action labels can vary slightly by iOS version.


Update an existing Shortcut to include checked-off reminders
Remove the Is Completed is false filter from Find Reminders; keep your list filters. Inside Repeat, read Is Completed from Repeat Item. Use If to output the Text true for completed items and the Text false otherwise. Set a variable named Completed Flag to this If Result. Add a Text field named completed to each reminder Dictionary and select Completed Flag as its value. Leave your existing title/list/due fields, JSON assembly, URL and token in place. Run the Shortcut again. The server accepts these text flags and displays completed items due today through the next four days; completed overdue items stay hidden.


    

  1. Add Find Reminders. Filter only for your chosen list(s); remove any Is Completed is false filter. Turn off its item limit. Export both incomplete and completed items. The server shows overdue incomplete items, plus all reminders due today through the next four Pacific calendar days. Do not restrict the Shortcut to due-today items.
    2. 

  2. Add Repeat with Each, using the found Reminders.
    3. 

  3. Inside Repeat, add Get Details of Reminders for Due Date of Repeat Item. Add If Due Date has any value. In that branch, Format Date with Custom format yyyy-MM-dd; in Otherwise use an empty Text action. After End If, use Set Variable to name this If Result Due Day. This trial exports due days, not times; keep the phone’s date timezone on Pacific.
    4. 

  4. Still inside Repeat, add Get Details of Reminders → Is Completed, selecting Repeat Item. Add If the completion value is true: a Text action containing true. In Otherwise, a Text action containing false. After End If, set a variable named Completed Flag to this If Result. These are lowercase text flags, making it unnecessary to bind a variable to a Dictionary Boolean switch.
    5. 

  5. Still inside Repeat, add a Dictionary with four text fields. Use the properties of Repeat Item for the first two:
    title → Title of Repeat Item
list  → List of Repeat Item (as text)
due   → Due Day (formatted date or empty text)
completed → Completed Flag (Text: true or false)
    Immediately after this Dictionary, inside Repeat, add Get Text from Input and select that Dictionary as its input. This serializes the reminder as JSON, preserving quotes and line breaks. Make Get Text the last action before End Repeat.
    6. 

  6. After End Repeat, add Combine Text. Select Repeat Results as its input and set its separator to Custom: one comma ,. Keep the input as Repeat Results, rather than selecting only its first item.
    7. 

  7. Add Current Date and Format Date → ISO 8601. Then add a Text action containing:
    {
  "version": 1,
  "capturedAt": "FORMATTED_DATE",
  "reminders": [
    COMBINED_TEXT
  ]
}
    Replace FORMATTED_DATE using Select Variable → Formatted Date, keeping its surrounding quotes. Replace COMBINED_TEXT using Select Variable → Combined Text, with no quotes around that variable. Leave the square brackets in place: zero reminders becomes []. No top-level Dictionary or Array field is needed. Do not type reminder titles directly into this JSON template.
    8. 

  8. Add Set Name to name that Text reminders.json. The next action sends these JSON bytes as a file body.
    9. 

  9. Add Get Contents of URL, using the upload URL above. Set Method → POST. Add these headers:
    Authorization → the full “Bearer …” value above
Content-Type  → application/json
    Set Request Body → File and choose the named reminders.json text from the preceding action. This sends the already assembled JSON, including its reminders array.
    10. 

  10. Add Show Result for the response. Run it once and approve Reminders/network access. A successful response includes "ok":true and a received count. A count of zero is a valid empty snapshot. Check the desktop Tasks panel for the same upload time, then select its lists.
    11. 



Example JSON for checking your Text output
{
  "version": 1,
  "capturedAt": "2026-11-05T08:00:00-08:00",
  "reminders": [
    {"title": "Buy milk", "list": "Home", "due": "2026-11-05", "completed": "false"},
    {"title": "Finished task", "list": "Home", "due": "2026-11-06", "completed": "true"}
  ]
}
The date is an example. Use Current Date, not this literal value. Do not include notes, contacts, attachments or your Apple password.


3. Try automatic delivery
Once the manual run works, remove Show Result. Create a Time of Day personal automation to run this shortcut before your briefing and choose Run Immediately (or disable Ask Before Running on older iOS). Test once while the phone is locked. The computer must be awake, the app running, and Tailscale connected on both devices.
Snapshots older than two hours show Unavailable. This trial does not run a print schedule. Nothing in the shortcut marks a reminder complete or changes it.
