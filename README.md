# Receipt Summary

A personal morning briefing printed on a receipt printer at home, combining personal information, work context, news, and market snapshots.

The project is in planning. Start with the [personal v1 wayfinder map](.scratch/personal-v1/map.md). Its decision tickets hold the questions and eventual answers; the map indexes resolved decisions.

The intended direction is an open-source project whose development can also be shared through social media. Publication and production implementation are later steps.
